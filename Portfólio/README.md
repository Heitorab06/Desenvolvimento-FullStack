# Portfólio - Heitor Alves Barreto

Portfólio moderno, responsivo e limpo desenvolvido em **React** com **Vite**, baseado no currículo profissional e foto de perfil.

## 🚀 Tecnologias Utilizadas

- **React 19**
- **Vite 6**
- **Lucide React** (ícones modernos e leves)
- **CSS3 Moderno** (design dark tech, glassmorphism, responsividade completa)

---

## 📂 Estrutura do Projeto

```
Portfólio/
├── public/
│   ├── foto.png                          # Foto de perfil
│   └── Curriculo_Heitor_Barreto.pdf      # Currículo para download
├── src/
│   ├── components/
│   │   ├── Navbar.jsx                    # Barra de navegação responsiva com menu mobile
│   │   ├── Hero.jsx                      # Apresentação, foto com glow, CTAs e redes
│   │   ├── About.jsx                     # Resumo profissional, formação e idiomas
│   │   ├── Projects.jsx                  # Projetos em destaque (Multiagentes e Dados)
│   │   ├── Experience.jsx                # Monitoria e atividades de nuvem (AWS)
│   │   ├── Skills.jsx                    # Habilidades categorizadas por IA, Dados, etc.
│   │   ├── Certifications.jsx            # Certificações e cursos com badges
│   │   ├── Contact.jsx                   # Cards de contato direto, cópia de e-mail e WhatsApp
│   │   └── Footer.jsx                    # Rodapé com atalho de voltar ao topo
│   ├── data/
│   │   └── portfolioData.js              # Informações centralizadas do currículo
│   ├── App.css                           # Estilos da aplicação
│   ├── index.css                         # Variáveis de cor e resets globais
│   ├── App.jsx                           # Componente raiz
│   └── main.jsx                          # Ponto de entrada
├── index.html
├── package.json
└── vite.config.js
```

## 🛠️ Como Executar o Projeto

1. **Acesse a pasta do projeto**:
   ```bash
   cd Portfólio
   ```

2. **Instale as dependências (se necessário)**:
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. **Gerar build de produção**:
   ```bash
   npm run build
   ```
