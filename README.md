# Desenvolvimento Full Stack

Este repositório reúne os projetos, exercícios e atividades desenvolvidos durante a disciplina de **Desenvolvimento Full Stack**.

O objetivo é organizar os materiais produzidos ao longo da disciplina, registrar o aprendizado e acompanhar a evolução dos projetos e práticas realizadas durante o semestre.

## Conteúdo

* Exercícios da disciplina
* Atividades práticas
* Projetos desenvolvidos
* Experimentos e materiais de estudo

> **Observação:** Este repositório possui fins acadêmicos e pode conter projetos em desenvolvimento e atualizações conforme o andamento da disciplina.
